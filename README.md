# 啾啾岛

啾啾的角色介绍、小岛场景与插画档案。纯静态站点，可直接部署到 GitHub Pages。

## 内容
- 角色介绍与多视角形象
- 饭馆、书屋、影院、账房四处场景
- 六大插画系列，按系列筛选与搜索
- 大图浏览、键盘切换与 WebP 下载
- 四封可以轮换的啾啾来信

## 素材与更新
图片位于 `assets/`；`assets.json` 记录标题、分类、尺寸和原素材文件名。网页使用优化的 WebP 副本，不替代设计源文件。

新增图片后，在 `assets.json` 添加一项，字段为 `id`（唯一数字）、`title`、`category`、`src`、`width`、`height`、`source`。现有分类需与 `app.js` 的 `categories` 对应。站点不含账号、在线写入或浏览器本地上传。

GitHub Pages 使用 `main` 分支的根目录，无需构建步骤。`.nojekyll` 禁用 Jekyll。
